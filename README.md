# Áurea Energia Sustentável

Landing page da Áurea, uma empresa fictícia de energia solar. É um projeto front-end estático, feito apenas com HTML, CSS e JavaScript. Não usa frameworks nem etapa de build.

## Funcionalidades

- **Página inicial** (`main/`): seções de destaque (hero), sobre e soluções, além de uma barra de busca que filtra os cards de soluções.
- **Página de login** (`login/`): formulários de login e cadastro, com um link para alternar entre eles.
- Fontes do Google Fonts (Inter, Montserrat, Space Grotesk).

## Estrutura do Projeto

```
├── assets/   # Imagens e ícones SVG
├── login/    # Página de login / cadastro (HTML, CSS, JS)
├── main/     # Página inicial (HTML, CSS, JS)
└── shared/   # Estilos base compartilhados (base.css)
```

## Como Executar

1. Clone ou baixe o repositório.
2. Abra `main/main.html` no navegador.

Você também pode servir a pasta com um servidor local, como a extensão Live Server do VS Code.

## Créditos

As fotos são do [Unsplash](https://unsplash.com). Os ícones são [Material Symbols](https://fonts.google.com/icons), do Google.
